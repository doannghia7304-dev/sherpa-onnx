# Voice Lock Screen Android Application

Ứng dụng **Voice Lock Screen** tích hợp đầy đủ **9 Giải Pháp Nhận Diện Giọng Nói & Mở Khóa Màn Hình** từ các thư viện, SDK và mô hình AI hàng đầu thế giới.

## Danh Sách 9 Giải Pháp Tích Hợp

1. **Sherpa-ONNX (Offline KWS)** - k2-fsa: [github.com/k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)
2. **Picovoice Porcupine & Eagle** - Picovoice Inc: [picovoice.ai](https://picovoice.ai)
3. **Tự Dựng GPU Backend (FastAPI)** - SpeechBrain: [github.com/speechbrain/speechbrain](https://github.com/speechbrain/speechbrain)
4. **Native Android OS STT** - Google Android OS: [developer.android.com](https://developer.android.com)
5. **Challenge-Response Biometrics** - ID R&D Voice SDK: [github.com/IDRND/idvoice-sdk-samples](https://github.com/IDRND/idvoice-sdk-samples) & Microsoft: [github.com/Microsoft/Cognitive-SpeakerRecognition-Android](https://github.com/Microsoft/Cognitive-SpeakerRecognition-Android)
6. **Vosk Mobile Speech SDK** - Alpha Cephei: [github.com/alphacep/vosk-api](https://github.com/alphacep/vosk-api)
7. **TensorFlow Lite Audio Task** - Google TensorFlow: [github.com/tensorflow/tensorflow](https://github.com/tensorflow/tensorflow)
8. **PocketSphinx Android** - CMU Sphinx: [github.com/cmusphinx/pocketsphinx-android](https://github.com/cmusphinx/pocketsphinx-android)
9. **Silero VAD + ONNX** - Silero AI: [github.com/snakers4/silero-vad](https://github.com/snakers4/silero-vad)
